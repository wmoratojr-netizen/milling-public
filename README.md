# milling-public

Arquivos públicos do app **Milling — Análise de Tiro Esportivo**, hospedados via GitHub Pages.

- `privacy-policy.html` — política de privacidade (exigida pela Google Play Store).
- `index.html` — landing simples que aponta para a política.

Este repo contém apenas o que precisa ficar público. O código-fonte do app é privado.
